# Repository operations for Codex

The current AGENTS.md and user request govern work. Inspect actual remotes, branch, status and relevant diffs before Git operations. Do not infer synchronization from old documentation or automatically stage, commit, push, pull or reset.

Keep this repository independent from sibling projects. Shared origins do not synchronize working trees automatically. The original repository-specific material is preserved in [.codex/legacy/GITHUB.md](.codex/legacy/GITHUB.md); read it for historical context and publication constraints, with obsolete commands superseded by current instructions.

Never publish secret files, wallet/signing keys, activation credentials or credential-bearing URLs. Match GitHub identity to the target owner. For the root portfolio, project directories and private migration snapshots remain excluded; root AmazonQ.md was already tracked before adoption, so its earlier local-only label was inaccurate.
